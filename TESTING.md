# Testing plan

The live checklist is a pinned issue: https://github.com/MuffinEMU/wiiu-ios-compatibility/issues/1

It lists the games we want to test, in three tiers, with a box per device for the first tier. Tick a box once the result is recorded.

**Devices we have so far:** A12Z iPad Pro (6 GB), iPad with an A16 chip, iPhone 15 Pro and iPhone 12. If you have another device, add it in a comment on the issue.

How to record a result is in [CONTRIBUTING.md](CONTRIBUTING.md).
